# Legislative pathways collection: scope and methods

## Why this increment

The older “Implement Explore Page Optimization” history was read with pagination, including the Part 2 collection/depth discussion and the subsequent discussion of policy survival. The available “Explore optimization audit,” “Best Website Direction,” and “Project ideas for college applications” chats were also inspected. The latter recent turns concern setup, design or outreach; they were not treated as research-topic choices.

The substantive recovered requests were to deepen the second investigation beyond surface-level counts, use multiple sources, and make useful, inspectable data. The existing 33-table package already contains selected 118th cosponsor/vote/ideology/text context. The earlier assistant suggested tracing apparently dead bills into other legislative vehicles, recurrence across Congresses, coalition changes and procedural pathways. Those were proposals, not a user-approved claim of novelty. The user explicitly pushed back on thousands of manual reviews. This increment therefore automates broader evidence collection and exposes candidate relationships, leaving consequential editorial claims for review.

Campaign finance, lobbying and spending categories were suggestions in the later handoff, not settled user priorities. FEC bulk access was tested successfully during reconnaissance but no FEC analytical dataset is included in this release. LDA, USAspending, CRS/GAO and hearing collections remain possible later increments after a specific research question is chosen; no records from them are claimed here. There is no record-size or admissions guarantee.

## Primary records acquired

1. **GovInfo BILLSTATUS:** eight complete type ZIPs, HR/S/HJRES/SJRES for Congresses 118 and 119, downloaded October 28, 2026. [Bulk access documentation](https://www.govinfo.gov/developers), [source schema/user guide](https://github.com/usgpo/bill-status). 33,591 measures: 16,565 from the completed 118th and 17,026 from the ongoing 119th. Simple/concurrent resolutions are excluded. ZIPs are retained by SHA-256 and each normalized row includes the archive hash, XML member name and XML record hash. The 11 tables expose bill metadata, dated cosponsors and withdrawals, source-ordered actions, committee assignments/events, source-asserted bill relationships, subjects, summaries, text-version references, CBO metadata and recorded-vote references. Some relationships point outside this restricted scope; 1,035 unmatched related-bill rows are retained rather than dropped. Blank source fields remain blank; the completeness CSV measures each field.
2. **House Clerk:** every unique 2024 House XML roll-call URL referenced by those acquired status records: 275 votes, 118,488 member positions, zero download failures. [Official XML documentation](https://xml.house.gov/), [vote metadata dictionary](https://xml.house.gov/rollcall/vote-metadata.html). This covers bill-linked votes on four measure types, not every House roll call or any Senate roll call. Vote questions, amendment numbers, procedure, dates, party labels, source member IDs and all positions are preserved. Each vote's positions reconcile to its official Yea/Aye, Nay/No, Present and Not Voting totals. An initial Senate XML request returned HTTP 403; no access restriction was bypassed. Earlier Senate extracts remain in the previous future package.
3. **GovInfo legislative text:** 40 official introduced/enrolled XML documents for a deterministic 24-pair feasibility pilot. Source population: a non-enacted 118th measure officially related to an enacted 118th measure, selecting the first 12 `Identical bill` and first 12 `Related bill` pairs in lexicographic bill-ID order. [Bill text documentation](https://www.govinfo.gov/help/bills). All requested XMLs were acquired. Twenty-two pairs have eligible sections; two short source texts have no 80-word section and remain documented. This is neither random nor representative. There are 2,148 eligible XML sections and 42 unreviewed lexical passage candidates.
4. **Member crosswalk:** 12,770 people, 45,535 service terms and 97,319 identifier rows from [unitedstates/congress-legislators](https://github.com/unitedstates/congress-legislators), pinned to commit `15530b7d621009eb5fc7eda67f75194d7d91f8c1`, with its CC0 license. This is community-maintained reference data, distinguished from the official records. Historical/current YAML, API commit metadata and license bytes are preserved locally. Terms and party-affiliation lists retain source dates; no name matching or assumed retrospective party labels were introduced.

GovInfo and House federal records retain source attribution; the roster has its own CC0 license. Newly collected tables do not include Voteview files or relicense any third-party material from prior packages. CBO rows are links/metadata supplied by bill status, not independently downloaded estimate pages or numerical budget scores. Text-version rows are references; only the 40 pilot documents were acquired in full. Committee-event rows are events, not a full dated membership roster. Amendments may be referenced by actions/votes; this release is not a comprehensive amendment-text collection.

## Research tables and opportunities

- **Recurring proposals:** 9,104 adjacent-Congress pairs have the same normalized title (at least 30 characters) and sponsor ID across the preserved 113–118 archive plus the new 119th snapshot. These are candidates. Titles can be generic; the rule misses renamed proposals or changed sponsors. Examine whether a recurring proposal's cosponsor coalition or committee trajectory changes before advancement. Keep the ongoing 119th out of completed-outcome denominators.
- **Support versus recorded behavior:** 4,743 bill-cosponsor/member-vote observations join the acquired House votes to official cosponsor events. The question, amendment number and exact position remain visible. There are 87 same-day timing ambiguities, not silently ordered events. Not Voting is retained as absence. A procedural Yea can have a different meaning from support for passage; no universal support percentage is published. This broadens the evidence trail for the prior bipartisanship question without replacing the earlier selected-cohort analysis.
- **Policy survival:** compare non-enacted standalone proposals with officially related enacted vehicles. For example, H.R. 1015 and enacted S. 2825 both carry the Dustoff Crews title; H.R. 10168 is officially related to the enacted H.R. 5009 defense vehicle. The acquisition includes introduced/enrolled texts and source passages. An automated pilot lowercases word/number tokens, forms unique five-word shingles per section with at least 80 tokens and keeps a best enrolled-section match at 50% source containment and 20 shared shingles. Shared boilerplate can pass; short surviving provisions inside long sections can be missed. Forty-two candidates are evidence for review, not verified incorporation, direction of influence or causal findings.
- **Committee/budget context:** use 61,752 committee event rows, 2,700 CBO references and source dates to ask which recurring or cross-party proposals reach institutional consideration. A missing CBO reference is not proof that no estimate exists, and a CBO link is not a fiscal impact value.

The collection is an auditable research foundation. Establishing novelty still requires a topic-specific literature/data review and testing a matching method against reviewed examples. Human effort can focus on selected findings rather than labeling every record.

## Validation and reproducibility

- ZIP integrity; parsed XML count equals bill count; unique bill/action IDs; parsed dates and all included child-table bill references.
- Independent CSV-reader row counts reconciled with Parquet. Explicit delimiters/quotes preserve late-appearing JSON and large summary fields. Source strings and missingness stay distinguishable.
- All House totals, vote/member uniqueness and member IDs validated. All acquired sponsor, cosponsor and House member Bioguide IDs match the pinned crosswalk; zero inferred name joins.
- New 118th bill IDs and introduction dates match the original archive. The original 76,867-bill/401,161-action release is unchanged. The newly downloaded 118th status snapshot contains the same 77,088 action rows; it remains a separate provenance snapshot.
- All 11 status tables reproduced byte-for-byte from cached raw bytes. All 21 new package table schemas/counts/checksums pass offline verification. Tests cover duplicate-looking actions, provenance, withdrawal dates, absence versus opposition, official vote-total disagreement, text eligibility, CSV quoting and failure recovery.

`warehouse/collection-cache/urls/` records each fetched URL and immutable content hash. Interrupted collection resumes at completed files; transient network resets receive bounded retries. Requests start no faster than one per 0.6 seconds per host within each collector, and collectors run sequentially per source type. This is completed-file caching, not a claim of byte-range resume or a live synchronization service. `--refresh` retrieves a fresh source version while old content objects remain. New publication names are required; existing packages are not overwritten. Failed builds leave the previous historical snapshot pointer intact.

Rebuild commands and the inventory are in the root README. No paid service or user-supplied API key was used. Raw cache snapshots remain on the Mac; GitHub contains compact Parquet, catalogs, checksums and methods. Full raw sources can be reconstructed from official URLs, but future upstream changes can prevent byte-identical reconstruction unless the preserved local raw objects are used. This is why their hashes and retrieval dates are retained.

No live WordPress deployment or UI change occurs.
