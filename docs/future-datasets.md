# Adding future datasets

Use `python scripts/import_csv.py path/to/file.csv --dataset committee-referrals --source-url https://official.example/source` to create an immutable raw CSV, lossless Parquet staging, row ordinals, retrieval metadata and checksums under `warehouse/datasets/<dataset>/<sha256>/`. Repeating the same bytes verifies and reuses the snapshot. No existing dataset is overwritten. CSVs with conflicting reserved provenance column names must be renamed explicitly in a source adapter, with the original retained.

Then write a dedicated SQL adapter, tests and methods for that source. Define stable IDs and Congress scope; validate schemas, missing values, joins, duplicate policy and date boundaries. Record licenses and source versions. Never load new records into the historical 113–118 snapshot or reuse its count assertions for another population. The 13 original empty core tables are schema proposals and remain untouched; they are not populated datasets.

The supplied Bipartisanship Depth v2 extracts for 33 tables have now been recovered and staged; see cloud-handoff.md. These are available for research review, with original methods and rights retained. Additional full-source normalization still needs adapters. Broader planned sources include: member terms (Congress/official member records), committee referrals (BILLSTATUS committee nodes), individual cosponsors (BILLSTATUS cosponsor nodes), roll calls and positions (House Clerk/Senate), amendments (Congress/GovInfo), and bill text versions (GovInfo). The historical archive supplies only aggregate cosponsor counts and action descriptions; these cannot reconstruct those missing entities. Future datasets have an ingestion path, not fabricated rows or claims of completion.

For large future collections, split inputs by Congress/source period, keep compressed Parquet and execute DuckDB queries directly against required files. Maintain immutable manifests and publish only validated research artifacts. Use GitHub release assets or other versioned public storage for raw archives rather than placing large sources in Git history.
