# Historical reconstruction v1

Population: all 76,867 HR, S, HJRES and SJRES measures in Congresses 113–118 from the supplied 2013–2024 data-and-methods archive. Companion vehicles remain separate. Congress membership determines inclusion; the latest introduction is January 3, 2025. These are the archived CSV records, not a new fetch of current GovInfo records.

The pipeline preserves exact archive members under each immutable snapshot's raw directory. All 12 per-Congress bill/action CSVs are staged as text with original file and one-based record ordinal (header excluded). Empty strings stay empty in staging. Normalized fields use typed dates and numbers; absent sponsor IDs become null. Original columns and milestone fields remain in historical_bill_features. Actions receive IDs from source file plus row, preserving identical source events without collapsing their counts. Sequence numbers are source order, not chronological legislative ordering.

Outcome is the supplied historical furthest_stage, not a newly inferred classification. The archive's parser and README define the hierarchy: enactment; veto without enactment; both chambers; one chamber; full committee report or discharge; committee activity; no recorded committee progress or chamber passage. See SOURCE_NOTES.md and the archived parser for precise action codes and fallbacks. The release includes 118_published_reconciliation.csv: 129 stage changes relative to the original 118th publication, plus date differences. This release reconstructs the standardized historical dataset; it does not reproduce every original website number unchanged.

Validation checks exact totals (76,867 bills, 401,161 actions), unique bill IDs, action links, parseable dates/counts, bill identity consistency and multiset equality of combined and per-Congress bill CSVs. It verifies all artifact hashes before promoting a current snapshot. Eleven sponsor IDs are missing in the source. Pre-introduction actions and identical action payloads are retained and counted in validation.json. The 568 actions preceding introduction include explicit pre-introduction hearings, but all cases have not been individually adjudicated; pre_introduction_actions.csv exposes them for audit. Do not use negative intervals as elapsed legislative processing times without an explicit rule.

Counts describe legislative vehicles and recorded activity, not whether policy ideas ultimately succeeded through other legislation. The source's identical-bill field does not detect all incorporation. Missing committee, roll-call, amendment, individual cosponsor and bill-text datasets are not represented as completed research. No live WordPress data or presentation changes occur.

Provenance: source archive retrieved through connected Drive; upstream manifest contains 24 GovInfo ZIP archive hashes and URLs. CSV hashes are independently recorded locally. The upstream XML checksums have not been reverified against downloaded XML archives in this build. Federal source material and supplied parser documentation are attributed in the archived source notes; review redistribution requirements for future non-federal inputs.
